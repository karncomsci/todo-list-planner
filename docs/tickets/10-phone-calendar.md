# 10: Phone Calendar

**What to build:** On a phone, the Calendar page is a compact month calendar with coloured dots for days with Tasks and, under it, the list of Tasks for the selected day. The Owner ticks Tasks done from that list.

**Repositories:** `planner-web`.

**Blocked by:** 09 (Edit and tick done from the Calendar)

**Status:** done

- [x] At phone width the Calendar shows the compact month calendar instead of the computer month View (D10, story 34)
- [x] Days with Tasks show dots coloured by Priority; Overdue Tasks show red; today is marked
- [x] Selecting a day lists that day's Tasks, including multi-day Tasks covering it
- [x] Each listed Task can be ticked done and opened for editing (story 35)
- [x] Month navigation and "today" work as on the computer View
